# Mon Projet Web – ProConnect

## 1. 🎨 Présentation du projet

### Concept
- Thème choisi : Plateforme de services
- Public cible : Particuliers et petits entrepreneurs proposant ou recherchant des services
- Objectifs du site : Mettre en relation des personnes ayant des compétences avec des clients potentiels, de manière simple et rapide.

### Fonctionnalités prévues
- Navigation : menu simple avec ancres
- Sections principales :  
  - Découvrir les talents  
  - Proposer un service
- Contenus proposés : cartes de services avec description, tarif et formulaire de contact

---

## 2. 📚 Parcours d'apprentissage

### Ressources utilisées
- MDN Web Docs (HTML, CSS, accessibilité)
- OpenClassrooms (bases HTML/CSS, responsive)
- freeCodeCamp (mise en page, formulaires)
- Documentation W3C (bonnes pratiques HTML)

### Progression
- Semaine 4 : structure HTML de base et premières sections
- Semaine 6 : mise en page CSS et styles globaux
- Semaine 8 : formulaires et validation des champs
- Semaine 10 : responsive design avec grid et media queries
- Semaine 11 : amélioration de l’accessibilité et lisibilité
- Semaine 12 : corrections finales, tests et validation

---

## 3. 🛠️ Outils et méthodologie

### Environnement de travail
- IDE : WebStorm
- Navigateurs de test : Google Chrome, Mozilla Firefox, Edge
- Versioning : webstorm + GitHub
- Validation : Validator W3C (HTML/CSS), tests manuels responsive

### Méthodologie
- Approche mobile-first
- Travail progressif par sections
- Tests réguliers après chaque modification
- Respect de la grille d’évaluation fournie

### Choix de design
- Palette de couleurs :
  - Couleur principale : `#3498db` – navigation et éléments principaux
  - Couleur secondaire : `#2ecc71` – éléments d’accent et tarifs
  - Couleur de texte : `#333333` – lisibilité
  - Couleur de fond : `#f5f5f5` – fond clair et neutre
- Typographies :
  - Titres : Poppins (via CSS)
  - Texte : Poppins (via CSS)

## 6. 🎯 Bilan personnel

### Ce que j’ai appris
- Structurer un site web avec du HTML sémantique
- Utiliser CSS Grid et media queries pour le responsive
- Améliorer l’accessibilité d’un site web
- Respecter une grille d’évaluation technique

### Difficultés rencontrées
- Gestion du responsive sur différentes tailles d’écran
- Organisation du CSS
- Correction des erreurs liées aux images et à l’accessibilité

### Réussites et fiertés
- Site fonctionnel et lisible sur tous les supports
- Formulaires bien structurés
- Progression visible par rapport au début du cours

### Améliorations possibles
- Ajout d’une vraie base de données
- Filtrage ou recherche des services
- Amélioration visuelle avec animations légères
